幻尔 LeArm 闭源 IK 库写死 pitch 角度导致 3D 空间大面积坐标解算失败

STM32 固件调用闭源 LeArm.lib 时使用固定 pitch=-40°，导致远/近/高/低位目标无法解算。通过在上位机实现分析几何 IK 并自动选择 pitch 解决。

现象

用 ros2 topic pub /arm_cmd 发送机械臂末端目标坐标时，某些区域的坐标（近点、远点、高位、低位）频繁返回 IK 解算失败。

if (!robot_arm_coordinate_set(x_value, y_value, z_value,
                              -40,        // ← pitch 硬编码为 -40°
                              -90.0f,     // wrist_roll
                              10.0f,      // gripper
                              60)) {      // time (×10ms)
    // 解算失败 → 蜂鸣器报警
    stop_flag = 1;
}

当 pitch 固定为 -40° 时，以下区域的目标坐标无法解算：

区域 为什么失败
近点 (X < 15cm) L4 在 -40° 时投影太长，2-link 无法折叠到这么近
远点 (X > 32cm) 手臂不够长，需要更平的 pitch 来延伸
高位近点 (Z > 18cm, X < 15cm) 需要 pitch > -20°，但被硬编码 -40° 锁死
低位远点 (Z < 5cm, X > 28cm) 需要 pitch < -60°，-40° 会撞桌子

分析

机械臂有 4 个旋转关节（底座 + 3 自由度），控制末端 3 个平移坐标 (X, Y, Z) → 有 1 个冗余自由度（pitch）。

闭源 LeArm.lib 将冗余自由度写死为 -40°，相当于把 4DOF 降级为 3DOF，只覆盖了 workspace 的一个子集。

解决

在上位机（ROS2 侧）实现分析几何 IK，自动从有效范围中选择 pitch，绕过 STM32 的闭源 IK。

IK 算法

将 4DOF 问题分解为经典子问题：

  1. 底座旋转 θ₁ = atan2(y, x)
  2. 投影到径向平面 r = √(x² + y²), h = z
  3. 扫描 pitch 空间 [-90°, 0°]，对每个 pitch：
    • 去除非 L4 贡献：r_w = r - L₄·cos(α), h_w = h - L₁ - L₄·sin(α)
    • 用余弦定理解 2-link IK
    • 检查关节限位
  4. 自动选择距离用户偏好（默认 -50°）最近的可行 pitch

def find_valid_pitch_range(r, h, pitch_step=1.0):
    """扫描 [-90°, 0°] 找到所有可行的 pitch 值"""
    valid = []
    for pitch_deg in range(-90, 1, pitch_step):
        pitch_rad = math.radians(pitch_deg)
        r_w = r - L4 * math.cos(pitch_rad)
        h_w = h - L1 - L4 * math.sin(pitch_rad)
        sols = solve_2link(r_w, h_w, L2, L3)
        if sols is None: continue
        for t2, t3 in sols:
            t4 = pitch_rad - t2 - t3
            if check_joint_limits(...):
                valid.append(pitch_deg)
                break
    return valid

def select_pitch(r, h, preferred_pitch_deg=-50.0):
    """选择最接近偏好的有效 pitch"""
    valid = find_valid_pitch_range(r, h)
    if not valid: return None
    return min(valid, key=lambda p: abs(p - preferred_pitch_deg))

知识点

  • 冗余自由度不要写死——闭源库的固定 pitch 是典型的"能用但不通用"的工程折衷
  • 分析几何 IK（余弦定理）比数值迭代更稳定、更快，不需要初始猜测
  • STM32 闭源库可以完全绕过——只把下位机当舵机驱动板用，IK 放在上位机做
  • DH 参数从固件 kinematics.h 直接提取，保证一致性：L1=2.89, L2=10.43, L3=8.9, L4=17.7 cm
  • theta2servo 映射因舵机物理安装方向有翻转：servo5 = 90° - θ₂（从 robot_arm.c 中 SERVO_TYPE=2 分支验证）

Linux常用命令

2026-04-27
2 minute read

1. 常用命令概览

1.1 文件与目录管理

  • ls / ls -l / ll: 列出目录内容
  • cd <dir>: 切换到指定目录
  • pwd: 显示当前工作目录
  • mkdir <dir>: 创建新目录
  • rm -rf <file/dir>: 强制级联删除文件或目录（高危）
  • cp -r <src> <dest>: 复制文件或目录
  • mv <src> <dest>: 移动/重命名文件或目录
  • touch <file>: 创建空文件或修改时间戳
  • cat <file>: 查看文件内容
  • less <file> / more <file>: 分页查看文件内容
  • tail -f <file>: 实时查看文件末尾内容（常用看日志）
  • head -n 10 <file>: 查看文件前10行
  • find <path> -name "*name*": 按名称查找文件或目录
  • find <path> -type d -name "*name*": 仅查找目录(文件夹)
  • find <path> -type f -name "*name*": 仅查找普通文件
  • grep "<text>" <file>: 在文件中搜索指定文本内容

1.2 系统与进程管理

  • top / htop: 实时显示系统进程状态和资源占用
  • ps -ef / ps aux: 查看所有活动进程
  • kill -9 <pid>: 强制终止指定进程
  • free -h: 查看内存和交换空间使用情况
  • df -h: 查看磁盘分区和使用情况
  • du -sh <dir>: 查看指定目录的大小
  • uname -a: 查看系统内核及硬件架构信息
  • history: 查看命令历史记录

1.3 网络操作

  • ping <ip/domain>: 测试网络连通性
  • ifconfig / ip addr: 查看网络接口和IP地址
  • netstat -tulnp / ss -tulnp: 查看端口占用情况
  • curl -O <url> / wget <url>: 下载文件
  • scp <file> user@host:<path>: 通过SSH远程安全传输文件
  • ssh user@host: 远程登录服务器

1.4 用户与权限管理

  • chmod 755 <file>: 修改文件或目录权限
  • chown user:group <file>: 修改文件或目录的所有者和所属组
  • su - <user>: 切换用户
  • sudo <command>: 以超级用户权限执行命令
  • useradd <user> / userdel <user>: 增加/删除用户
  • passwd <user>: 修改用户密码

2. Vim常用快捷键与命令

Vim 主要有三种模式：普通模式（Command Mode）、插入模式（Insert Mode） 和 底线命令模式（Last line Mode）。

2.1 模式切换

  • i: 在光标前插入（进入插入模式）
  • a: 在光标后插入（进入插入模式）
  • o: 在当前行下方新建一行并插入
  • O: 在当前行上方新建一行并插入
  • ESC: 退出或返回普通模式
  • :: 进入底线命令模式（须在普通模式下）

2.2 光标移动（普通模式下）

  • h/j/k/l: 左/下/上/右 移动
  • w / b: 移动到下一个单词开头 / 移动到上一个单词开头
  • 0 (数字零) / ^: 移动到行首 / 移动到非空白行首
  • $: 移动到行尾
  • gg: 移动到文件开头第一行
  • G: 移动到文件最后一行
  • nG / <n> + shift+g: 移动到第 n 行
  • Ctrl+f / Ctrl+b: 向下/向上翻页
  • Ctrl+d / Ctrl+u: 向下/向上翻半页

2.3 文本编辑（普通模式下）

  • x: 删除光标所在字符
  • dd: 删除/剪切当前行
  • ndd: 向下删除/剪切 n 行
  • yy: 复制当前行
  • nyy: 向下复制 n 行
  • p: 粘贴到光标后/下方
  • P: 粘贴到光标前/上方
  • u: 撤销上一步操作
  • Ctrl+r: 恢复撤销（重做）
  • v: 字符可视化模式（结合方向键选择文本）
  • V: 行可视化模式
  • r: 替换光标所在的单个字符

2.4 查找与替换（底线及普通模式）

  • /keyword: 向下查找 keyword，按 n 找下一个，按 N 找上一个
  • ?keyword: 向上查找 keyword
  • :%s/old/new/g: 全局替换文档中的 old 为 new
  • :n1,n2s/old/new/g: 在第 n1 行到第 n2 行之间替换 old 为 new

2.5 保存与退出（底线命令模式）

  • :w: 保存修改
  • :q: 退出（若未修改）
  • :q!: 强制退出（不保存修改）
  • :wq / :x: 保存并退出
  • ZZ: 保存并退出（普通模式下的大写ZZ）

3. 其他高效快捷键 (终端/Shell)

  • Ctrl+C: 终止当前运行的命令
  • Ctrl+Z: 将当前进程挂起至后台
  • Ctrl+D: 退出当前终端/退出SSH会话 (EOF)
  • Ctrl+L: 清屏 (等同于 clear 命令)
  • Ctrl+A: 快速移动光标至命令行行首
  • Ctrl+E: 快速移动光标至命令行行尾
  • Ctrl+R: 搜索历史执行过的命令
  • Ctrl+U: 删除光标所在位置到行首的字符
  • Ctrl+K: 删除光标所在位置到行尾的字符
  • Tab: 自动补全命令或文件路径

Windows 11 安装 Ubuntu xx.04 WSL2 并迁移到目标盘盘

在 Windows 11 上安装 Ubuntu 24.04 WSL2，将发行版放到 F 盘，并配置 GitHub SSH 的完整记录

2026-07-27
3 minute read
loading... 次

背景

这篇记录用于在 Windows 11 上准备一个 Ubuntu 24.04 的 WSL2 环境，并把 WSL 发行版本体放到 F 盘，方便后续备份、迁移和轻量开发。

目标环境：

1
2
3
4

Windows 11
Ubuntu-24.04 WSL2
WSL 系统本体：F:\wsl-distros\Ubuntu-24.04
备份包目录：F:\wsl-backup

1. 更新 WSL

打开管理员 PowerShell，先更新 WSL 并查看当前状态：

1
2
3

wsl --update
wsl --version
wsl --status

然后设置以后新安装的发行版默认使用 WSL2：

1

wsl --set-default-version 2

2. 查看可安装发行版

继续在 PowerShell 中执行：

1

wsl --list --online

如果列表中能看到：

1

Ubuntu-24.04

就可以继续安装。

3. 方案 A：直接安装 Ubuntu 24.04 到 F 盘

先创建 WSL 存储目录：

1
2

mkdir F:\wsl-distros
mkdir F:\wsl-distros\Ubuntu-24.04

直接安装到 F 盘：

1

wsl --install -d Ubuntu-24.04 --location F:\wsl-distros\Ubuntu-24.04

安装完成后启动：

1

wsl -d Ubuntu-24.04

第一次进入会提示创建 Linux 用户名和密码。密码输入时不会显示，这是正常现象。

进入 Ubuntu 后检查版本：

1

cat /etc/os-release

确认看到 Ubuntu 24.04 相关信息即可。

4. 方案 B：如果 –location 不支持，使用 export/import 迁移

如果执行 wsl --install ... --location ... 时提示不支持 --location，就先正常安装，再导出、注销、导入到 F 盘。

先正常安装：

1

wsl --install -d Ubuntu-24.04

如果下载异常，也可以尝试：

1

wsl --install --web-download -d Ubuntu-24.04

安装完成后先启动一次，创建 Linux 用户：

1

wsl -d Ubuntu-24.04

进入后确认系统版本：

1
2

cat /etc/os-release
exit

回到 PowerShell，关闭 WSL：

1

wsl --shutdown

创建迁移目录和备份目录：

1
2
3

mkdir F:\wsl-distros
mkdir F:\wsl-backup
mkdir F:\wsl-distros\Ubuntu-24.04

导出当前 Ubuntu 24.04：

1

wsl --export Ubuntu-24.04 F:\wsl-backup\Ubuntu-24.04-clean.tar

注销原来的发行版前，必须确认 tar 备份包已经存在：

1

dir F:\wsl-backup\Ubuntu-24.04-clean.tar

确认文件存在后，再注销原发行版：

1

wsl --unregister Ubuntu-24.04

注意：wsl --unregister 会删除这个发行版里的数据。没有确认 tar 备份前，不要执行这一步。

然后从 tar 包导入到 F 盘：

1

wsl --import Ubuntu-24.04 F:\wsl-distros\Ubuntu-24.04 F:\wsl-backup\Ubuntu-24.04-clean.tar --version 2

导入完成后启动：

1

wsl -d Ubuntu-24.04

5. 设置默认发行版

在 PowerShell 中执行：

1
2
3

wsl --set-default-version 2
wsl --set-default Ubuntu-24.04
wsl -l -v

希望看到类似结果：

1
2

  NAME            STATE           VERSION
* Ubuntu-24.04    Stopped         2

如果 VERSION 是 2，说明当前发行版已经是 WSL2。

6. 导入后设置默认用户

如果通过 wsl --import 导入，启动后可能默认进入 root 用户。假设你的普通用户名是 user，先进入 Ubuntu：

1

wsl -d Ubuntu-24.04

查看 /home 下是否有原来的普通用户：

1

ls /home

如果能看到：

1

user

就写入 /etc/wsl.conf：

1
2
3
4

sudo tee /etc/wsl.conf > /dev/null <<'EOF'
[user]
default=user
EOF

退出 Ubuntu：

1

exit

回到 PowerShell，重启 WSL：

1
2

wsl --shutdown
wsl -d Ubuntu-24.04

再次进入后应该默认是普通用户。

如果 /home 下没有普通用户，可以新建一个：

1
2

adduser user
usermod -aG sudo user

然后再写 /etc/wsl.conf。

7. Ubuntu 初始化

进入 Ubuntu 后更新系统并安装常用工具：

1
2
3

sudo apt update
sudo apt upgrade -y
sudo apt install -y git curl wget build-essential ca-certificates gnupg lsb-release vim nano unzip openssh-client

8. 配置 Git 用户名和邮箱

在 Ubuntu 里配置 Git 身份：

1
2

git config --global user.name "Your GitHub name"
git config --global user.email "Your Email@example.com"

检查配置：

1

git config --global --list

9. 配置 GitHub SSH

9.1 生成 ed25519 SSH key

在 Ubuntu 里执行：

1

ssh-keygen -t ed25519 -C "你的邮箱@example.com"

默认保存路径通常是：

1

~/.ssh/id_ed25519

一路回车即可。是否设置 passphrase 看个人习惯：设置更安全，不设置更方便。

9.2 启动 ssh-agent 并添加私钥 

1
2

eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519

如果提示权限过宽，可以修正权限：

1
2
3

chmod 700 ~/.ssh
chmod 600 ~/.ssh/id_ed25519
chmod 644 ~/.ssh/id_ed25519.pub

9.3 查看公钥 

1

cat ~/.ssh/id_ed25519.pub

复制输出的整行内容，格式通常是：

1

ssh-ed25519 AAAA... 你的邮箱@example.com

9.4 添加到 GitHub

打开 GitHub：

1

GitHub -> Settings -> SSH and GPG keys -> New SSH key

填写：

1
2

Title: WSL Ubuntu 24.04
Key: 粘贴 ~/.ssh/id_ed25519.pub 的内容

保存即可。

9.5 测试 SSH 连接

回到 Ubuntu，执行：

1

ssh -T git@github.com

第一次连接会提示确认 GitHub 主机指纹，输入：

1

yes

如果成功，会看到类似：

1

Hi 用户名! You've successfully authenticated, but GitHub does not provide shell access.

这说明 SSH 已经配置好。

10 设置sudo免密码：

打开visudo

1

sudo visudo

在文件最后加一行，把 你的用户名 换成实际用户名：

1

你的用户名 ALL=(ALL) NOPASSWD:ALL

Ctrl + O + Ctrl + X退出

1
2

sudo -k
sudo whoami

测试，如果直接输出root，说明修改成功

11. 推荐目录习惯

WSL 系统本体建议放：

1

F:\wsl-distros

不要放到项目目录里。项目目录、系统目录和备份目录最好分开：

1
2
3

F:\wsl-distros    # WSL 发行版本体
F:\wsl-backup     # WSL 导出的 tar 备份
F:\workspace      # Windows 侧项目、资料、仓库

WSL 内部开发目录建议放：

1

~/workspace/project

不要把需要频繁编译、索引、安装依赖的项目长期放到：

1

/mnt/f

12. 最终检查清单

安装完成后，在 PowerShell 检查：

1

wsl -l -v

在 Ubuntu 检查：

1
2
3
4

cat /etc/os-release
whoami
git --version
ssh -T git@github.com

如果这些都正常，就说明：

  1. Ubuntu 24.04 WSL2 已安装完成。
  2. 发行版本体已经放到 F 盘。
  3. 默认用户已经配置好。
  4. Git 和 GitHub SSH 已经可以使用。

小结

这套环境适合承担 Windows 侧的 Linux 工具链、Git、文档和轻量开发任务。
